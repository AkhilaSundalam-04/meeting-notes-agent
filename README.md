# Meeting Notes Agent

## Project Overview

Meeting Notes Agent is an AI-powered application that automatically extracts important discussion points from meeting transcripts and generates concise summaries.

The application is built using Python and Streamlit and helps users save time by converting lengthy meeting conversations into actionable notes.

---

## Features

- Upload meeting transcripts
- Extract important discussion points
- Generate concise meeting summaries
- User-friendly Streamlit interface
- Supports multiple transcript files
